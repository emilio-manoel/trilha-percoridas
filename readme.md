## 📌 Sobre o Projeto

O **Trilha Percorrida** é um projeto pessoal criado para registrar minha trajetória de aprendizado e evolução no desenvolvimento de software.

Sua primeira versão surgiu durante meus estudos na **Digital Innovation One (DIO.me)**, como parte de um projeto prático de um curso voltado aos fundamentos do desenvolvimento web, utilizando HTML, CSS e JavaScript.

Com o passar do tempo, novos conhecimentos foram adquiridos e surgiu a oportunidade de revisitar esse projeto. Decidi então reconstruí-lo utilizando **React, TypeScript e Vite**, transformando sua estrutura original em uma aplicação baseada em componentes.

Mais do que atualizar uma página, a intenção foi utilizar o próprio projeto como uma forma de demonstrar minha evolução técnica, permitindo comparar minhas primeiras experiências com o desenvolvimento web e os conhecimentos que possuo atualmente.

---

## 📈 Evolução do Projeto

Uma das principais características deste repositório é a possibilidade de acompanhar duas etapas diferentes da minha formação.

### 🟢 Versão 1 — HTML, CSS e JavaScript Vanilla

A primeira versão foi desenvolvida com o apoio da **DIO.me**, durante um curso sobre os fundamentos do desenvolvimento web. O projeto serviu como atividade prática para aplicar os conhecimentos apresentados ao longo dos estudos.

Nessa etapa, foram trabalhados:

- **HTML5:** estruturação do conteúdo utilizando elementos da própria linguagem;
- **CSS3:** estilização da página, organização dos elementos e aplicação de layouts;
- **JavaScript:** utilização de JavaScript puro para complementar o comportamento da página;
- **Flexbox:** organização e distribuição dos elementos na interface;
- **Media Queries:** adaptação do layout para diferentes tamanhos de tela.

A estrutura era construída diretamente no HTML, com os estilos concentrados em arquivos CSS e os scripts executados pelo próprio navegador.

🔗 **Acessar a primeira versão:** [Branch v1](https://github.com/emilio-manoel/trilha-percoridas/tree/v1)

### ⚛️ Versão Atual — React, TypeScript e Vite

Na versão atual, o projeto foi completamente reestruturado utilizando tecnologias modernas do ecossistema JavaScript.

A principal mudança foi a adoção da componentização, permitindo dividir a interface em partes independentes e reutilizáveis.

Entre as melhorias estão:

- Utilização do React para construção da interface;
- TypeScript para tipagem e maior segurança no código;
- Separação da aplicação em componentes;
- Organização dos estilos por componentes;
- Melhor estruturação dos arquivos e recursos;
- Utilização do Vite como ambiente de desenvolvimento e build.

Essa reconstrução representa uma mudança importante na maneira como organizo e desenvolvo aplicações front-end.

---

## 🛠️ Tecnologias Utilizadas na Versão Atual

### ⚛️ React

O React é responsável pela construção da interface através de componentes reutilizáveis.

A aplicação foi dividida em quatro componentes principais: `Header`, `Main`, `Aside` e `Footer`, facilitando a organização e a manutenção do código.

### 🔷 TypeScript

O TypeScript foi adotado para adicionar tipagem estática ao projeto, proporcionando maior segurança, legibilidade e organização durante o desenvolvimento.

### ⚡ Vite

O Vite é utilizado como ferramenta de desenvolvimento e build, oferecendo inicialização rápida, atualização instantânea durante a programação e otimização dos arquivos para publicação.

### 🎨 CSS3

O CSS continua sendo utilizado para definir a identidade visual da aplicação, controlar layouts, espaçamentos, cores e responsividade.

A diferença está na organização dos arquivos de estilo, que acompanha a separação dos componentes da aplicação.

---

## 🧩 Organização da Aplicação

A versão atual utiliza uma estrutura baseada em componentes, separando as principais áreas do website.

| Componente | Responsabilidade |
|---|---|
| `App.tsx` | Organiza e reúne os componentes principais. |
| `Header` | Apresentação pessoal e introdução do projeto. |
| `Main` | Apresentação das tecnologias e seus benefícios. |
| `Aside` | Exibição dos objetivos e conhecimentos futuros. |
| `Footer` | Reúne links para redes sociais e plataformas. |

Essa organização facilita futuras modificações, permitindo trabalhar em uma parte específica da aplicação sem precisar concentrar toda a estrutura em um único arquivo.
